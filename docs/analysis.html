Step Script What it does
Load scripts/01_data_loading.R Reads the three station exports (long format: one row per timestamp and variable)
Clean scripts/02_data_cleaning.R Parses and rounds timestamps to the hour, pivots to one row per station-hour, applies range checks and detects faulty sensors

Rscript run_all.R runs the four steps; quarto render builds this site.

2. Data cleaning

Timestamps. Readings arrive on the hour, sometimes a few seconds late (07:00:02), so they are rounded to the hour before reshaping. Midnight timestamps needed care: converting them back to text drops the time part, which silently lost 310 midnight readings in an earlier version of this analysis.

Range checks. Values outside physical limits (temperature outside −20 to 60 °C, humidity outside 0 to 100 %, wind above 60 m/s, solar above 1,400 W/m²) are set to missing. None were found.

Sensor fault detection. A working solar sensor reads close to 0 W/m² at night. Each station’s median reading between 20:00 and 05:00 is checked:

Code 
quality %>%
  transmute(Station = city,
            `Median night-time solar (W/m²)` = round(median_night_solar, 1),
            Verdict = if_else(solar_sensor_ok, "OK", "Faulty: solar readings removed")) %>%
  kable()
Station Median night-time solar (W/m²) Verdict
Bizerte 0.0 OK
Kef 954.1 Faulty: solar readings removed
Sousse 0.0 OK

Kef’s sensor reports 945 to 958 W/m² around the clock, so all its solar values are excluded. Without this check, Kef would appear to receive ten times more sunlight than the coastal stations.

Common period. The stations cover different dates (Sousse runs until 6 January), so cities are compared only on the hours between 07 Dec 01:00 and 19 Dec 2025 05:00.

Humidity is strongly and negatively linked to temperature everywhere: relative humidity drops when the air warms up during the day. Temperature and wind are moderately positive, consistent with winds picking up during the warmer afternoon hours.

## 2. Data cleaning

**Timestamps.** Readings arrive on the hour, sometimes a few seconds late (`07:00:02`), so they are rounded to the hour before reshaping. Midnight timestamps needed care: converting them back to text drops the time part, which silently lost 310 midnight readings in an earlier version of this analysis.

**Range checks.** Values outside physical limits (temperature outside −20 to 60 °C, humidity outside 0 to 100 %, wind above 60 m/s, solar above 1,400 W/m²) are set to missing. None were found.

**Sensor fault detection.** A working solar sensor reads close to 0 W/m² at night. Each station's median reading between 20:00 and 05:00 is checked:

Kef's sensor reports 945 to 958 W/m² around the clock, so all its solar values are excluded. Without this check, Kef would appear to receive ten times more sunlight than the coastal stations.
