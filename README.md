## 🔍 TROUBLESHOOTING

### Package Not Found:
```r
install.packages("PACKAGE_NAME")
library(PACKAGE_NAME)
```

### Data Not Found:
```r
library(here)
here()  # Check your location
list.files("data/raw")  # Check files
```

### Plot Not Showing:
```r
dir.create("output/figures", recursive = TRUE)
source("scripts/04_visualizations.R")
```

### Quarto Not Found:
```bash
export PATH="/opt/quarto-1.5.57/bin:$PATH"
echo 'export PATH="/opt/quarto-1.5.57/bin:$PATH"' >> ~/.bashrc
```

## 💡 PRO TIPS

1. **Always run from project root**: `cd tunisia-climate-capstone`
2. **Use RStudio**: Easier than terminal for beginners
3. **Check here()**: `library(here); here()` shows your location
4. **Preview first**: Use `quarto preview` before `quarto render`
5. **Save often**: Commit to Git after each working version

## 🆘 EMERGENCY FIX

If everything breaks:
```bash

cd ..

# 2. Re-run setup
./setup_project.sh

# 3. Copy data again
cp YOUR_DATA_LOCATION/*.csv tunisia-climate-capstone/data/raw/

# 4. Try again
cd tunisia-climate-capstone
Rscript run_all.R
```
